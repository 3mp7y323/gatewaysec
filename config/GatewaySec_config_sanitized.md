## A.4 L3 — ModSecurity WAF (Docker Compose)

`/home/gwuser/waf/docker-compose.yml` — official OWASP CRS image, host networking (required so L2 can reassemble HTTP on the host chains), blocking mode on, CRS Paranoia 1 / inbound anomaly 5, JSON audit log. Backend is the webserver over ZeroTier (`198.51.100.221:8081`). Recreate with `docker compose down && up -d` after any bind-mounted edit (inode change).

```yaml
# =============================================================================
# GatewaySec - LAYER 3 WAF (topology ZeroTier)
# =============================================================================
# Image owasp/modsecurity-crs:nginx — Nginx + ModSecurity v3 + OWASP CRS sẵn.
#
# Topology:
#   Attacker → Gateway ens33 (WAN) → WAF host-network :8080/:8443
#            → proxy về Web qua ZeroTier: 198.51.100.221:8080
#
# host network: nginx trong container bind THẲNG port host (không DNAT),
# để L2 Suricata ráp được HTTP 2 chiều (bài học từ phiên trước).
# =============================================================================
services:
  waf:
    image: owasp/modsecurity-crs:nginx
    container_name: gatewaysec-waf
    network_mode: host          # bind thẳng port host, KHÔNG DNAT (quan trọng cho Suricata)
    restart: unless-stopped
    environment:
      # ===== BACKEND: Web server qua ZeroTier =====
      BACKEND: "http://198.51.100.221:8081"   # Web .221 nghe 8080
      # WAF nghe port host (unprivileged user → phải >1024)
      PORT: "8080"
      SSL_PORT: "8443"
      PROXY_MANAGE_CONFD: "on"
      # Header chuẩn reverse-proxy ($$ = escape cho compose)
      # ===== ModSecurity: chế độ chặn thật =====
      MODSEC_RULE_ENGINE: "On"        # On = chặn (403). DetectionOnly = chỉ log
      # ===== OWASP CRS tuning =====
      PARANOIA: "1"                   # PL1 = ít false positive (phù hợp demo)
      ANOMALY_INBOUND: "5"            # tổng điểm ≥5 → chặn
      ANOMALY_OUTBOUND: "20"
      PROXY_SSL: "off"
      PROXY_TIMEOUT: "60s"
      # ===== Log: JSON cho ELK/Wazuh sau này =====
      MODSEC_AUDIT_LOG_FORMAT: "JSON"
      MODSEC_AUDIT_ENGINE: "RelevantOnly"
      MODSEC_AUDIT_LOG: "/var/log/modsecurity/modsec_audit.json"
    volumes:
      - ./logs:/var/log/modsecurity
```

## A.5 Capture pipeline — `rolling-ai`

```ini

[Install]
```

**Pipeline script** (`/home/gwuser/rolling_ai_pipeline.sh`) — tcpdump 60s window → CICFlowMeter 4.0 → SSH-append to `wazuhelk:~/ai-engine/live_flows.csv` (with header-init guard):

```bash
#!/bin/bash
# rolling_ai_pipeline.sh @ may1 — AI pipeline TU DONG (ban 3)
# Moi vong: tcpdump bat DUNG 60s -> dong file -> cfm doc -> day CSV sang wazuhelk.
# Tuan tu, KHONG dung -G rotate (tranh tcpdump va script gianh file).
#
# FIX ban 3: neu file live_flows.csv ben wazuhelk RONG/CHUA CO -> gui CA HEADER.
#   (Ban 2 luon dung `tail -n +2` bo header -> khi file bi xa sach thi mat header
#    -> pandas hieu nham dong data thanh ten cot -> thieu 59/59 feature -> AI mu.)
#
# Cai dat:
#   cp rolling_ai_pipeline.sh ~/ && chmod +x ~/rolling_ai_pipeline.sh
#   sudo systemctl restart rolling-ai
set -u

CFM="/home/gwuser/CICFlowMeter/build/distributions/CICFlowMeter-4.0/bin/cfm"
PCAPDIR="/home/gwuser/rolling_pcap"
CSVDIR="/home/gwuser/rolling_csv"
WAZUH="wazuhelk@198.51.100.103"
REMOTE_CSV='$HOME/ai-engine/live_flows.csv'
IFACE="ens33"
PORT_FILTER="not port 22 and not port 9993 and not host 198.51.100.103"          # de trong "" neu muon bat toan bo traffic
WINDOW=60                        # cua so bat goi moi vong (giay)
MIN_PCAP=500                     # pcap nho hon (byte) coi nhu rong, bo qua

export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
mkdir -p "$PCAPDIR" "$CSVDIR"

echo "[rolling] bat dau | iface=$IFACE | cua so=${WINDOW}s | filter='${PORT_FILTER}'"

while true; do
  TS=$(date +%Y%m%d_%H%M%S)
  PCAP="$PCAPDIR/cap_$TS.pcap"

  # --- 1) bat goi DUNG WINDOW giay roi tu thoat ---
  timeout $((WINDOW + 5)) tcpdump -i "$IFACE" -G "$WINDOW" -W 1 \
      -w "$PCAP" -Z root $PORT_FILTER >/dev/null 2>&1

  # --- 2) bo qua pcap rong / qua nho (khong co flow) ---
  if [ ! -s "$PCAP" ] || [ "$(stat -c%s "$PCAP")" -lt "$MIN_PCAP" ]; then
    echo "[rolling] $TS: pcap rong/nho, bo qua"
    rm -f "$PCAP"
    continue
  fi

  # --- 3) CICFlowMeter doc pcap -> CSV 84 cot ---
  "$CFM" "$PCAP" "$CSVDIR" >/dev/null 2>&1
  CSV="$CSVDIR/cap_$TS.pcap_Flow.csv"

  if [ -s "$CSV" ]; then
    N=$(( $(wc -l < "$CSV") - 1 ))          # tru dong header

    # --- 4) day sang wazuhelk ---
    # Neu file ben kia CO DU LIEU -> chi gui data (bo header, tranh lap).
    # Neu RONG/CHUA CO           -> gui CA HEADER (giu dung 84 cot cho pandas).
    if ssh "$WAZUH" "test -s $REMOTE_CSV" 2>/dev/null; then
      tail -n +2 "$CSV" | ssh "$WAZUH" "cat >> $REMOTE_CSV" \
        && echo "[rolling] $TS: day $N flow sang wazuhelk"
    else
      cat "$CSV" | ssh "$WAZUH" "cat >> $REMOTE_CSV" \
        && echo "[rolling] $TS: day $N flow + HEADER (khoi tao file) sang wazuhelk"
    fi

    rm -f "$CSV"
  else
    echo "[rolling] $TS: cfm ra 0 flow"
  fi

  rm -f "$PCAP"                              # xoa pcap sau khi xu (khong day dia)
done
```

```bash
# Hoi peer qua ZeroTier

for i in $(seq 1 15); do
    PEER_RESP=$(curl -s --max-time 3 http://${PEER_ZT}:9797/ 2>/dev/null)
    [ -n "$PEER_RESP" ] && break
    sleep 2
done
```

## B.2 ML inference engine (`serve_ai_engine.py`)

The complete engine: feature-contract loading (`feature_list.json`), the deterministic V4→2017 column rename + `norm()` alignment (defeats train/serve skew), scaler + XGBoost + Isolation Forest load, late fusion `0.6·XGB + 0.4·IF`, gates `BLOCK_GATE=0.90` / `SUSPECT_GATE=0.50`, and the compact `verdict.json` writer. Runtime venv: xgboost 3.3.0, scikit-learn 1.9.0, numpy 2.5.1, Python 3.12.

```python
"""
serve_ai_engine.py — AI Engine (out-of-band) cho GatewaySec.

VAI TRÒ: đứng giữa CICFlowMeter và model. Nhận feature 1 flow -> khớp đúng
hợp đồng train -> XGBoost + Isolation Forest -> fusion -> verdict. Nếu ĐỦ tin
cậy (XGB >= 0.9) thì ghi verdict cho Wazuh Active Response chặn IP.

KHÔNG tự chặn gói. KHÔNG nằm trên packet path. Chỉ đọc feature, phán, rồi
đẩy verdict cho Wazuh AR thực thi (gwsec-drop). Đây là điểm defense.

ARTIFACT cần (copy từ máy teammate sang, để cùng thư mục):
  xgboost_model.json   iforest_model.pkl   scaler.pkl   feature_list.json

CHẠY:
  # chế độ batch (đọc CSV do CICFlowMeter xuất từ pcap) — dùng để test/demo tái lập
  python3 serve_ai_engine.py --csv /tmp/flows.csv
  # chế độ watch (poll file CSV live CICFlowMeter đang ghi)
  python3 serve_ai_engine.py --watch /tmp/flows_live.csv
"""
import pandas as pd
import numpy as np
import json, joblib, re, os, time, argparse
import xgboost as xgb

# ============================================================
# CẤU HÌNH — chốt theo kiến trúc đã thống nhất
# ============================================================
ART_DIR      = "."                                   # thư mục chứa 4 artifact
VERDICT_OUT  = "/var/log/ai-engine/verdict.json"     # Wazuh <localfile> đọc file này
W_XGB, W_IF  = 0.6, 0.4                               # trọng số late fusion
BLOCK_GATE   = 0.90   # CHỈ XGBoost >= ngưỡng này mới cho Active Response chặn
SUSPECT_GATE = 0.50   # fused >= ngưỡng này -> alert "suspicious" (KHÔNG chặn)
# IF chỉ đóng góp vào score cảnh báo, TỰ NÓ không bao giờ kích block (FPR cao).

# ============================================================
# norm() — GIỐNG HỆT align_datasets.py để map tên cột CICFlowMeter -> tên train
# (CICFlowMeter nhả "Tot Fwd Pkts", train lưu "Total Fwd Packets" -> cùng key)
# ============================================================
ABBREV = {
    "tot": "total", "pkts": "packets", "pkt": "packet", "len": "length",
    "fwd": "fwd", "bwd": "bwd", "byts": "bytes", "cnt": "count",
    "seg": "segment", "init": "init", "win": "window", "flg": "flag",
    "hdr": "header", "iat": "iat", "std": "std", "avg": "average",
    "max": "max", "min": "min", "mean": "mean", "var": "variance",
    "act": "active", "subflow": "subflow", "blk": "bulk", "dst": "destination",
    "src": "source", "ts": "timestamp", "prot": "protocol", "dur": "duration",
    # TODO: nếu checkpoint khớp cột báo THIẾU feature length/totlen, bổ sung ở đây:
    # "totlen": "totallength", "pktlen": "packetlength",
}

def norm(col: str) -> str:
    c = str(col).strip().lower()
    c = c.replace("/", " ").replace("_", " ").replace("-", " ").replace(".", " ")
    c = re.sub(r"[^a-z0-9 ]", "", c)
    return "".join(ABBREV.get(w, w) for w in c.split())

# ============================================================
# BẢNG RENAME: CICFlowMeter Java V4 (serve) -> CICIDS2017 V3 (train)
# V4 đổi tên 13 cột so với V3 (số ít/nhiều, đảo thứ tự từ, CWR/CWE...).
# Feature TÍNH GIỐNG HỆT, chỉ khác tên -> map tay tất định.
# ĐÃ VERIFY: sau rename, norm() khớp 71/71 feature CICIDS2017, RỚT 0.
# ============================================================
RENAME_V4_TO_2017 = {
    "Dst Port": "Destination Port",
    "Total Fwd Packet": "Total Fwd Packets",
    "Total Bwd packets": "Total Backward Packets",
    "Total Length of Fwd Packet": "Total Length of Fwd Packets",
    "Total Length of Bwd Packet": "Total Length of Bwd Packets",
    "Packet Length Min": "Min Packet Length",
    "Packet Length Max": "Max Packet Length",
    "CWR Flag Count": "CWE Flag Count",
    "Fwd Segment Size Avg": "Avg Fwd Segment Size",
    "Bwd Segment Size Avg": "Avg Bwd Segment Size",
    "FWD Init Win Bytes": "Init_Win_bytes_forward",
    "Bwd Init Win Bytes": "Init_Win_bytes_backward",
    "Fwd Act Data Pkts": "act_data_pkt_fwd",
    "Fwd Seg Size Min": "min_seg_size_forward",
}


class AIEngine:
    def __init__(self, art_dir=ART_DIR):
        # --- feature contract (SOURCE OF TRUTH = file train xuất) ---
        self.feature_list = json.load(open(os.path.join(art_dir, "feature_list.json")))
        self.feat_key2name = {norm(f): f for f in self.feature_list}  # key -> tên train
        self.feat_keys_ordered = [norm(f) for f in self.feature_list]  # ĐÚNG thứ tự train

        # --- scaler + models ---
        self.scaler = joblib.load(os.path.join(art_dir, "scaler.pkl"))
        self.xgb = xgb.XGBClassifier()
        self.xgb.load_model(os.path.join(art_dir, "xgboost_model.json"))
        self.iforest = joblib.load(os.path.join(art_dir, "iforest_model.pkl"))

        # --- calibrate IF về [0,1] KHÔNG cần min-max theo batch ---
        # score_samples: cao = bình thường, thấp = bất thường. offset_ = ngưỡng.
        # anomaly = offset_ - score  (>0 = bất thường). Bọc sigmoid -> [0,1].
        self._if_offset = float(getattr(self.iforest, "offset_", -0.5))
        # TODO: scale này nên hiệu chỉnh bằng phân bố score trên tập train benign.
        # Tạm để 20 (đủ tách). Muốn khớp CHÍNH XÁC eval (min-max) thì train phải
        # lưu (raw.min, raw.max) ra if_norm.json rồi load ở đây.
        self._if_scale = 20.0

        print(f"[AIEngine] {len(self.feature_list)} feature | "
              f"IF offset={self._if_offset:.4f} | gate XGB>={BLOCK_GATE}")

    # ---------- 1) map + xếp cột incoming -> ma trận đúng thứ tự train ----------
    def _align_features(self, df: pd.DataFrame):
        # B0: rename cột V4 -> tên 2017 (tất định) TRƯỚC khi norm-match
        df = df.rename(columns=RENAME_V4_TO_2017)
        incoming = {norm(c): c for c in df.columns}          # key -> tên incoming
        missing = [k for k in self.feat_keys_ordered if k not in incoming]
        if missing:
            # feature train có mà CICFlowMeter KHÔNG nhả -> điền 0 + cảnh báo.
            # Nếu missing NHIỀU -> sai bản CICFlowMeter, verdict sẽ rác.
            miss_names = [self.feat_key2name[k] for k in missing]
            print(f"[WARN] thiếu {len(missing)}/{len(self.feature_list)} feature "
                  f"(điền 0): {miss_names[:8]}{'...' if len(miss_names)>8 else ''}")

        cols = []
        for k in self.feat_keys_ordered:
            if k in incoming:
                cols.append(pd.to_numeric(df[incoming[k]], errors="coerce"))
            else:
                cols.append(pd.Series(np.zeros(len(df)), index=df.index))
        X = pd.concat(cols, axis=1)
        X.columns = self.feature_list                        # đúng tên + thứ tự train
        X = X.replace([np.inf, -np.inf], np.nan).fillna(0.0)  # serve KHÔNG drop dòng
        return X, missing

    # ---------- 2) lấy IP nguồn (metadata, KHÔNG phải feature) để chặn ----------
    @staticmethod
    def _extract_src_ip(df: pd.DataFrame):
        for c in df.columns:
            if norm(c) in ("sourceip", "srcip"):
                return df[c].astype(str).values
        return np.array(["0.0.0.0"] * len(df))               # không có -> không chặn

    # ---------- 3) chấm điểm 1 batch flow ----------
    def score(self, df: pd.DataFrame):
        src_ips = self._extract_src_ip(df)
        X, _ = self._align_features(df)
        Xs = self.scaler.transform(X)

        p_xgb = self.xgb.predict_proba(Xs)[:, 1]             # xác suất attack
        raw = self.iforest.score_samples(Xs)                 # cao=normal, thấp=bất thường
        anomaly = self._if_offset - raw                      # >0 = bất thường
        p_if = 1.0 / (1.0 + np.exp(-self._if_scale * anomaly))  # sigmoid -> [0,1]

        fused = W_XGB * p_xgb + W_IF * p_if

        results = []
        for i in range(len(df)):
            block = bool(p_xgb[i] >= BLOCK_GATE)             # CHỈ XGB gate mới chặn
            if block:
                verdict = "malicious"
            elif fused[i] >= SUSPECT_GATE:
                verdict = "suspicious"                       # alert-only, KHÔNG chặn
            else:
                verdict = "benign"
            results.append({
                "src_ip": src_ips[i],                        # gwsec-drop regex đọc field này
                "verdict": verdict,
                "block": block,
                "xgb_conf": round(float(p_xgb[i]), 4),
                "if_score": round(float(p_if[i]), 4),
                "fused": round(float(fused[i]), 4),
            })
        return results

    # ---------- 4) ghi verdict cho Wazuh AR (chỉ ghi cái đáng ghi) ----------
    def emit(self, results):
        os.makedirs(os.path.dirname(VERDICT_OUT), exist_ok=True)
        n = 0
        with open(VERDICT_OUT, "a") as f:
            for r in results:
                if r["verdict"] == "benign":
                    continue                                 # đừng spam benign vào SIEM
                r["ts"] = time.strftime("%Y-%m-%dT%H:%M:%S")
                # compact (không cách) để khớp regex gwsec-drop: "src_ip":"..."
                f.write(json.dumps(r, separators=(",", ":")) + "\n")
                n += 1
                tag = "BLOCK" if r["block"] else "alert"
                print(f"  [{tag}] {r['src_ip']} xgb={r['xgb_conf']} "
                      f"fused={r['fused']} -> {r['verdict']}")
        return n


def run_csv(engine, path):
    df = pd.read_csv(path, low_memory=False)
    print(f"[+] {len(df)} flow từ {path}")
    engine.emit(engine.score(df))


def run_watch(engine, path, poll=2.0):
    """Poll file CSV live: chỉ xử dòng MỚI (theo số dòng đã đọc)."""
    print(f"[+] watch {path} (Ctrl-C để dừng)")
    seen = 0
    while True:
        try:
            if os.path.exists(path):
                df = pd.read_csv(path, low_memory=False)
                if len(df) > seen:
                    engine.emit(engine.score(df.iloc[seen:]))
                    seen = len(df)
            time.sleep(poll)
        except KeyboardInterrupt:
            print("\n[+] dừng."); break
        except Exception as e:
            print(f"[!] {e}"); time.sleep(poll)


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--csv", help="đọc 1 file CSV CICFlowMeter rồi thoát (batch/demo)")
    ap.add_argument("--watch", help="poll file CSV live, xử dòng mới")
    ap.add_argument("--art", default=ART_DIR, help="thư mục chứa 4 artifact")
    args = ap.parse_args()

    engine = AIEngine(args.art)
    if args.csv:
        run_csv(engine, args.csv)
    elif args.watch:
        run_watch(engine, args.watch)
    else:
        print("Cần --csv <file> hoặc --watch <file>")
```

## B.6 XAI integration — Qwen2.5 with RAG + dedup

Two files: the shell shim `custom-ollama` that `integratord` invokes, and the deployed `custom-ollama.py` (RAG from `mitre_kb.json`, 600 s per-IP dedup, writes `xai.json`). Model `qwen2.5:3b` on the Ollama node (`198.51.100.88:11434`), temp 0.3, num_predict 400.

**Deployed shim + script** (`/var/ossec/integrations/custom-ollama` and `custom-ollama.py`):

```python
--- /var/ossec/integrations/custom-ollama ---
#!/bin/sh
DIR_NAME="$(cd $(dirname "$0"); pwd -P)"
/usr/bin/env python3 "${DIR_NAME}/custom-ollama.py" "$@"
--- /var/ossec/integrations/custom-ollama.py ---
#!/usr/bin/env python3
# custom-ollama.py @ wazuhelk — XAI co RAG (tra MITRE knowledge base truoc khi hoi Qwen)
# alert -> lay MITRE ID -> tra mitre_kb.json -> nhet tri thuc vao prompt -> Qwen giai thich
# -> ghi xai.json (Wazuh doc localfile -> rule 100600 -> Dashboard)
import sys, json, urllib.request, os, time

OLLAMA  = "http://198.51.100.88:11434/api/generate"
MODEL   = "qwen2.5:3b"
XAI_OUT = "/var/log/ai-engine/xai.json"
KB_PATH = "/var/ossec/integrations/mitre_kb.json"   # dat KB canh script
DEDUP_PATH = "/var/log/ai-engine/xai_dedup.json"   # cache chong ngop
DEDUP_WINDOW = 600   # giay: 1 IP chi giai thich 1 lan / 10 phut

def should_explain(src_ip):
    # True = can giai thich; False = da giai thich gan day, skip
    try:
        cache = json.load(open(DEDUP_PATH, encoding="utf-8"))
    except Exception:
        cache = {}
    now = time.time()
    last = cache.get(src_ip, 0)
    if now - last < DEDUP_WINDOW:
        return False
    cache[src_ip] = now
    # don cache cu (>1h) tranh phinh file
    cache = {ip: t for ip, t in cache.items() if now - t < 3600}
    try:
        json.dump(cache, open(DEDUP_PATH, "w", encoding="utf-8"))
    except Exception as e:
        sys.stderr.write(f"[dedup] khong ghi duoc cache: {e}\n")
    return True

def load_kb():
    try:
        return json.load(open(KB_PATH, encoding="utf-8"))
    except Exception:
        return {}

def build_prompt(a, kb):
    rule = a.get("rule", {}); data = a.get("data", {})
    mitre_ids = rule.get("mitre", {}).get("id", []) or []
    srcip = data.get("src_ip") or data.get("srcip") or "?"
    conf  = data.get("xgb_conf", "?")

    # RAG: tra tri thuc MITRE tu KB (fallback DEFAULT neu khong co)
    mid = mitre_ids[0] if mitre_ids else "DEFAULT"
    kb_entry = kb.get(mid, kb.get("DEFAULT", {}))
    tri_thuc = (f"Ky thuat: {kb_entry.get('ten','')}\n"
                f"Mo ta chuan: {kb_entry.get('mo_ta','')}\n"
                f"Muc nguy hiem: {kb_entry.get('nguy_hiem','')}\n"
                f"Cach xu ly chuan: {kb_entry.get('xu_ly','')}")

    return (
        "Ban la chuyen gia SOC. Day la MOT CANH BAO THAT tu he thong IDS GatewaySec, "
        "thong tin da DAY DU. TUYET DOI KHONG xin loi, KHONG noi thieu thong tin.\n\n"
        f"[Du lieu canh bao]\nIP tan cong: {srcip}\nMITRE: {mid}\nDo tin cay AI: {conf}\n\n"
        f"[Tri thuc MITRE tham chieu]\n{tri_thuc}\n\n"
        "Dua vao tri thuc tren, viet giai thich tieng Viet GON (3 muc, moi muc 1-2 cau):\n"
        "1. Ke tan cong dang lam gi.\n2. Muc nguy hiem voi he thong.\n"
        "3. Khuyen nghi xu ly cu the.\n"
        "Tra loi NGAY, khong mo dau ruom ra."
    )

def ask_ollama(prompt):
    body = json.dumps({"model": MODEL, "prompt": prompt, "stream": False,
                       "options": {"num_predict": 400, "temperature": 0.3}}).encode()
    req = urllib.request.Request(OLLAMA, data=body,
                                 headers={"Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=90) as r:
        return json.loads(r.read()).get("response", "").strip()

def main():
    alert = json.load(open(sys.argv[1]))
    data  = alert.get("data", {})
    srcip = data.get("src_ip", "?")
    if not should_explain(srcip):
        return   # da giai thich IP nay gan day -> skip, tranh ngop XAI node
    kb    = load_kb()
    try:
        explanation = ask_ollama(build_prompt(alert, kb))
    except Exception as e:
        explanation = f"[LLM loi: {e}]"
    out = {"integration": "ollama-xai", "src_ip": srcip,
           "ai_explanation": explanation,
           "mitre": (alert.get("rule", {}).get("mitre", {}).get("id", []) or ["-"])[0],
           "orig_rule": alert.get("rule", {}).get("id", "")}
    with open(XAI_OUT, "a", encoding="utf-8") as f:
        f.write(json.dumps(out, ensure_ascii=False, separators=(",", ":")) + "\n")

if __name__ == "__main__":
    main()
```
